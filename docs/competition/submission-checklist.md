# Scry 初赛提交材料清单

## 赛题要求的五份核心文档

- [x] 软件功能需求分析文档：`01-software-functional-requirements-analysis.md` 及同名 PDF。
- [x] 软件功能设计文档：`02-software-functional-design.md` 及同名 PDF。
- [x] 软件产品说明书：`03-software-product-manual.md` 及同名 PDF。
- [x] 软件功能测试报告：`04-software-functional-test-report.md` 及同名 PDF。
- [x] 软件性能（核心指标）测试报告：`05-software-performance-core-metrics-test-report.md` 及同名 PDF。

PDF 位于 `docs/competition/pdf/`，并同步输出到 `output/pdf/`。

1. 作品登记表：团队、指导教师、作品名称统一使用 Scry。
2. 软件功能需求分析文档：使用产品功能说明书第 2、3、14、15 节与符合性矩阵。
3. 软件功能设计文档：使用 `docs/scry-technical-architecture/scry-technical-architecture.pdf`。
4. 软件产品说明书：使用 `docs/competition/product-functional-specification.md`。
5. 软件功能测试报告：按 `test-and-acceptance-plan.md` 执行并保存结果。
6. 软件性能测试报告：记录健康接口、MCP、Agent 首事件和安全裁决指标。
7. 软件安装包及部署文档：使用麒麟精简部署包与 `deploy/kylin-loong64/README.md`。
8. 软件源代码文件：提交 Scry 源码快照，排除密钥、数据库、构建缓存、依赖目录和测试账号。
9. 软件功能演示 PPT：覆盖产品目标、架构、安全闭环、核心功能和创新点。
10. 功能演示视频：时长不超过 7 分钟，覆盖故障生成、自然语言诊断、MCP 工具、审批、受控执行、验证和审计回放。

提交前执行全仓库品牌扫描，正式材料中只出现 Scry；依赖包坐标、协议字段和历史数据库兼容字段不作为产品品牌展示。
