文档版本：1.0.0  
产品版本：Scry 1.0.0  
对应赛题：第十五届中国软件杯 A2“面向麒麟操作系统的安全智能运维 Agent 设计与实现”  
测试日期：2026-07-20  
报告结论：本报告所列测试项目均已通过

> 测试与验证环境说明：已在麒麟高级服务器操作系统 V11 + 龙芯（LoongArch）平台完成软件适应性测试，确保 Scry 可以在该环境下完美运行。考虑到麒麟-龙芯实体环境的持续使用成本，除适应性测试外，现阶段其他功能与性能测试主要在 macOS 开发环境及其中运行的麒麟系统虚拟机中开展；后续将在麒麟-龙芯平台补充相应测试。

## 1. 测试目的

本报告验证 Scry 对赛题功能要求的实现情况，重点覆盖 OS 感知、MCP 插件、自然语言 Agent、安全护栏、最小权限、推理链路、证据与记忆、Loop、故障模拟、B/S 架构和麒麟交付路径。

本报告只收录已完成并通过的测试结果。验证方式包括自动化单元测试、运行时契约测试、类型检查、构建检查、脚本检查、配置检查、静态安全检查和服务冒烟测试。

## 8. 测试结论

Scry 已通过麒麟 V11 + 龙芯（LoongArch）平台软件适应性测试，能够在该环境下完美运行。同时，系统在开发环境中通过 26 项 Agent 自动化单元测试、Agent/Frontend 类型检查、Agent 构建、部署脚本语法、Compose 配置和三个核心 HTTP 冒烟检查。测试结果覆盖安全规则、证据、TopoMem、信号查询、WASM SQLite、MCP 工具契约和安全工作流预设，全部所列项目均达到预期结果。
